# Security Policy

If you find a security issue or an accidentally exposed secret in this repository, **do not open a public issue**. Instead:

1. Use **Security → Report a vulnerability** on the repository page, or
2. Contact the team members directly.

Any exposed key must be revoked and regenerated on the provider side (Hugging Face, W&B, OpenAI, etc.) right away. Removing it from the commit history alone is not enough.
